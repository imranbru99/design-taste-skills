# Examples

Teaching specimens for the skills in this repository. They are not a component library and not a template to copy into unrelated products.

| File | What it is |
| --- | --- |
| [gallery.html](gallery.html) | A self-contained page. Three before/after pairs for a fictional tile studio. No build step. |
| [before-after.md](before-after.md) | The same three pairs, as decisions rather than pixels. |
| [images/](images/) | Crops of the gallery, used in the repository README. |

Open the gallery directly:

```bash
xdg-open examples/gallery.html
```

Or pass `?shot=hero`, `?shot=capabilities`, or `?shot=queue` to show a single pair. Those views are what the README images are captured from.

If every page you design after reading this uses Maren's palette, Newsreader, and a glaze grid, you have learned the wrong lesson. The method is the 3-second sentence, the structure, and the refusal. The clay colors belong to a kiln.
